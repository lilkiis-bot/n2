# N2 60일 단어장

[단어장 열기](https://lilkiis-bot.github.io/n2/)

하루 20개, 60일 동안 공부하는 일본어 단어장입니다. 히라가나·한국어 뜻·예문·단어 및 예문 음성, 일차 시험, 누적 복습을 제공합니다.

## 모바일 학습과 듣기

- 단어 카드의 하단을 좌우로 쓸면 원하는 단어로 바로 이동합니다. 카드의 위치와 크기는 유지됩니다.
- 한자에는 Noto Serif JP 명조체를 적용했습니다. 교재에 쓰인 일본어 문자 1,266개의 글리프를 확인했으며, 전체 글꼴도 대체 글꼴로 함께 제공합니다. 글꼴 라이선스는 `dist/fonts/OFL.txt`에 있습니다.
- 주요 메뉴의 **듣기**에서 1일, 5일 묶음(1–5일, 6–10일 등), 전체 60일을 선택합니다. 각 단어의 일본어 발음이 세 번, 한국어 뜻이 한 번 재생됩니다.
- 선택 범위 반복, 이전·다음 단어, 재생 위치 이동, 음성 파일 내려받기를 지원합니다. 듣기 위치와 반복 설정도 이 기기에 저장됩니다.
- 화면 잠금 중에도 단어를 이어 들을 수 있도록 각 범위를 하나의 MP3로 제공하며 잠금 화면의 미디어 제어에 연결합니다. 첫 재생은 사용자가 눌러야 합니다. 실제 기기의 운영체제·브라우저에 따른 백그라운드 재생 차이는 있을 수 있습니다.
- 듣기만으로 일차가 완료되지는 않습니다. 일차 시험을 끝까지 풀면 완료됩니다.
- 복습 시험은 한자·발음·주제가 비슷한 단어를 보기로 우선 제시하며, 답을 고른 뒤 네 보기의 한자·읽기·뜻을 비교할 수 있습니다. 같은 뜻 표현이나 읽기가 중복되는 보기는 제외합니다.
- 예문은 내부 스크롤 없이 표시합니다. 같은 일차 안에서는 긴 예문에 맞춘 공간을 미리 확보해 단어를 넘길 때 카드가 움직이지 않습니다.
- 단어 음성은 재생기 하나를 재사용하고 가까운 단어만 미리 불러옵니다. 메모리에는 최대 8개 음성을 유지하며, 이전 재생 요청은 취소하고 지연된 요청에는 대체 음성을 사용합니다.

`scripts/build-listening.py`는 기존 일본어 음성과 생성한 한국어 음성을 합쳐 73개의 MP3와 시간표를 만듭니다. `edge-tts`, `imageio-ffmpeg`가 필요하며 중간 파일은 Git에서 제외한 `qa/`에 저장합니다. 긴 음성은 서비스 워커 캐시에 넣지 않고 브라우저의 범위 요청으로 재생합니다.

## 학습 기록

- 단어 위치, 완료한 회차, 별표, 오답, 진행 중인 시험은 각 기기·브라우저의 localStorage에 자동 저장됩니다.
- 날짜가 바뀌거나 브라우저를 닫아도 같은 주소와 브라우저로 돌아오면 이어서 공부할 수 있습니다.
- 서버나 GitHub 저장소에 개인 학습 기록을 올리지 않습니다. 기기 간 자동 동기화는 제공하지 않습니다.
- 브라우저의 사이트 데이터 삭제, 비공개 탐색, 저장 공간 정리는 기록을 지울 수 있습니다. 설정의 **기록 백업**으로 보관해 주세요.
- 기존 주소에서 이동할 때는 기존 사이트의 **기록 백업** 파일을 새 사이트의 **백업 가져오기**로 불러옵니다.

## GitHub Pages

저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다. `main`에 변경 사항을 올리면 `.github/workflows/pages.yml`이 단어·음성과 시험 로직을 검사하고 `dist/`를 공개합니다. 별도의 서버나 로그인은 필요하지 않습니다.

수정 뒤 `node scripts/check.mjs --require-audio`와 `node --test scripts/core.test.mjs`로 확인할 수 있습니다. `python -m http.server 4173 --directory dist`로 로컬 미리보기를 실행합니다.

`dist/core.js`의 저장 키는 기존 백업과의 호환성을 위해 유지합니다. 공개 주소를 바꾸면 `dist/phone-qr.svg`도 새 주소에 맞춰 갱신해 주세요.

이 단어장은 N3 기초 보완과 N2 대비를 위한 자체 자료입니다. 합격에는 문법·독해·청해 학습도 필요합니다.
